# make.fun frontend

A fast, responsive make.fun explorer for live bounties, bounty details, leaderboards, and public builder profiles. The static app reads make.fun's public API and includes no build step.

Serve `app/` as the document root with any static HTTP server. For example, from the repository root run `python3 -m http.server 8080 --directory app` and open `http://localhost:8080`.
